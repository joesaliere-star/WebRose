# Бордовая роза

Анимированная ASCII-роза в одном HTML-файле. Цветок нарисован только буквами, цифрами и знаками: стебель растёт, бутон раскрывается, роза медленно вращается и искрится. По трём быстрым кликам она рассыпается на частицы и собирается в сердце.

Без сборки, без зависимостей и без сервера. Достаточно открыть `index.html` в браузере.

## Запуск

Локально: скачайте репозиторий и откройте `index.html` двойным кликом.

Онлайн через GitHub Pages:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту страница появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Подойдёт и любой другой хостинг статичных страниц (Cloudflare Pages, Neocities и так далее): загрузите `index.html` как есть.

## Управление

| Действие | Результат |
|---|---|
| Потянуть цветок вбок (мышью или пальцем) | повернуть розу |
| Три быстрых клика или тапа по цветку | роза рассыпается на частицы и собирается в сердце |
| Ещё три клика по сердцу | сердце рассыпается и снова становится розой |
| Кнопка «Заново» | начать анимацию с роста стебля |
| Кнопка «Пауза» | остановить и продолжить |

Клики считаются тройными, если между ними не больше полсекунды и курсор почти не двигался.

## Как это устроено

Всё считается в браузере на обычном Canvas 2D, без WebGL и без изображений.

1. **Форма.** Головка розы задаётся параметрической поверхностью: спираль лепестков с волнистым краем. Это около 77 000 точек, плюс стебель и два листа. Всего около 83 000 точек с нормалями.
2. **Анимация.** Стебель и листья вырастают вдоль своей оси. Бутон раскрывается, когда по поверхности отодвигается граница видимой части.
3. **Проекция.** Точки поворачиваются, проецируются на сетку символов (84 × 58 ячеек, на узких экранах 60 × 42) и сравниваются по глубине. Для каждой ячейки остаётся ближайшая точка.
4. **Свет.** Два источника: неподвижный и движущийся. Для каждой ячейки считаются диффузный свет, блик и подсветка по краю, а у центра цветка добавляется затенение.
5. **Символы.** Яркость переводится в символ из шкалы `.,:;!i1tlIfjLCOQ0#8%@` и в один из 40 оттенков бордового (у стебля и листьев зелёного).
6. **Искры.** Над цветком поднимаются золотистые и розовые частицы-символы.
7. **Рассыпание.** Символы розы разлетаются по траекториям от центра, затем по кривым летят в сердце. Сердце строится по неявной кривой, а освещается как выпуклая поверхность. Количество символов в нём подгоняется под количество в розе.

## Адаптация под телефон

- Размер сетки зависит от ширины экрана.
- На устройствах с касанием анимация ограничена 30 кадрами в секунду.
- Страница не перерисовывается из-за сворачивания адресной строки Safari.
- Двойной тап не увеличивает страницу.
- При включённом `prefers-reduced-motion` анимация отключена, роза показывается сразу в раскрытом виде.

## Настройка

Основные параметры в начале скрипта в `index.html`:

| Переменная | Что меняет |
|---|---|
| `COLS` | число колонок сетки (больше значит мельче и детальнее, но тяжелее) |
| `RAMP` | шкала символов от тёмных к светлым |
| `BLOOM_T0`, `BLOOM_D` | задержка и длительность раскрытия бутона |
| `NT`, `NR` | число точек поверхности головки по виткам и по радиусу |
| `PAL` | цвета лепестков и зелени |

## Технологии

- HTML, CSS, JavaScript без сборки и без библиотек.
- Шрифты [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) и [Bodoni Moda](https://fonts.google.com/specimen/Bodoni+Moda) подключаются с Google Fonts. Без интернета страница работает на системных шрифтах, нужен только моноширинный.

## Браузеры

Современные Chrome, Safari, Firefox и Edge. Нужны Canvas 2D и Pointer Events.
